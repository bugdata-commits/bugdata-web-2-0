# BugData Web 2.0 Delivery Checklist

## Premium homepage experience

- [x] The separate BugData Web 2.0 prototype presents a world-class, mobile-first homepage without modifying the current live-site repository.
- [x] The hero communicates practical growth infrastructure for Zimbabwean businesses across AI automation, local SEO, hosting and reliability, and digital growth.
- [x] The homepage provides a primary `Book an assessment` action and a secondary `See how we help` action.
- [x] The homepage includes original BugData signal-board visual language, not copied protected layouts, wording, branding, screenshots, or animations from reference websites.

## Navigation and conversion

- [x] The header includes Services, Approach, Results, Insights, Contact, a separate Client portal route, and a primary assessment action.
- [x] The mobile navigation is keyboard-accessible, uses large touch targets, and keeps the booking action visible.
- [x] The page includes a WhatsApp-first assessment handoff, phone/email alternatives, and a short form without inventing backend submission behavior.
- [x] The page includes a `Choose your goal` path for getting found locally, automating work, improving reliability, and growing demand.

## Offer clarity and proof

- [x] The page includes four service pathways: AI Automation, Local SEO, Hosting & Reliability, and Digital Growth.
- [x] The page shows a Diagnose → Build → Launch → Improve process with operational annotations.
- [x] The page includes transparent proof/measurement language and does not publish invented client logos, rankings, leads, revenue, uptime, ROI, or performance statistics.
- [x] The page includes three scoped package concepts: Visibility, Automation, and Growth Operations.
- [x] The page includes technical reassurance for backups, security, support, integrations, and low-bandwidth delivery.

## Accessibility, SEO, and delivery

- [x] Initial HTML contains meaningful content, route-specific metadata, canonical/social metadata, and semantic headings.
- [x] `manus-routes.json` is served successfully and reflects all public prototype routes.
- [x] `sitemap.xml`, `robots.txt`, and the web manifest are present and consistent with the prototype routes.
- [x] Reduced-motion, visible focus, semantic controls, labels, and keyboard interaction states are implemented.
- [x] Desktop and mobile preview layouts are checked before delivery.
- [x] The prototype is committed to the separate public GitHub repository named `bugdata-web-2-0`; the managed Webdev project also has the same checkpoint.
